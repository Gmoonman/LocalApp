## ADDED Requirements

### Requirement: 用户与应用运行时隔离
插件 SHALL 按 Server 已认证用户、应用、身份和供应商区分运行时，且只向调用者返回其用户对应的运行时。

#### Scenario: 两个用户使用相同会话 ID
- **WHEN** 两个已认证用户在同一应用使用相同会话 ID
- **THEN** 两人使用不同的真实 dsh Harness，历史和模型配置不互相出现

### Requirement: 创建和停止协调
插件 SHALL 串行处理同一运行时的创建和替换，并将创建中的条目计入容量；设置失效或停止插件后不得保留晚创建的运行时。

#### Scenario: 创建期间停止插件
- **WHEN** 工厂尚未完成时停止 Cordis 插件
- **THEN** 创建结果被关闭，等待者得到失败，服务拒绝新请求

#### Scenario: 设置变更期间创建完成
- **WHEN** 对应用户或应用设置失效时创建仍在进行
- **THEN** 旧配置结果被关闭，其他用户和应用不受影响
